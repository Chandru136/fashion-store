# Project branding

- Use **Sudha Collections** for all existing and new pages, metadata, messages, examples, and documentation.
- Use `SC-` as the brand prefix for generated order numbers, product SKUs, and sample transaction identifiers.
- Use `sudha_collections_session_user` consistently for the session cookie.
- Use `sudha-collections` or `sudha_collections` when a machine-readable brand name is required.
- Keep changes limited to the requested scope; preserve unrelated code and behavior.
